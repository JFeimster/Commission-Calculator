# Four independent visual systems

1. Punk Utility Brutalism: black, electric green, hard corners, uppercase display, angular stripe art, split model/results panels.
2. Broker’s Manifesto: paper, ink, acid lime, orbital/architectural vector collage, double rules, numbered sections, ledger-style output.
3. Lime Precision Fintech: dark hero with embedded actual calculator, light full-width results dashboard, soft radius, pale lime metrics.
4. Pastel Intelligence: lavender/sky/pastel hero illustration, rounded controls, mint/butter/peach metric tiles.

All use semantic control IDs and a shared interaction layer. Per-variant `theme.json` describes transferable tokens and principles. Original lightweight SVG artwork is embedded in the HTML; no external font or illustration services are required. The exact reference PNGs were not available, so art direction is based on the supplied written descriptions, not pixel reproduction. System font fallbacks are intentional.
